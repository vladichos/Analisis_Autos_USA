# Analisis Autos USA
Analisis de un set de datos de autos usados en USA.
En este proyecto para un cliente ocupe R para realizar un analisis de los vehiculos de segunda mano vendidos en USA, el dataset esta sacado de la pagina craighlist que actualmente es la principal via para vender autos de segunda en USA.

Porfavor referirse al archivo Analisis_Autos.md para leer el reporte completo.
